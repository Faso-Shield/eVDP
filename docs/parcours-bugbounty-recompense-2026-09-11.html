Ce que cette session démontre

  • Séparation des rôles réelle : celui qui propose (Analyste) n'est jamais celui qui approuve (Coordinateur) — vérifié en changeant physiquement de compte, pas seulement en théorie.
  • La confidentialité tient : le chercheur voit sa récompense payée, jamais les délibérations internes qui y ont mené.
  • Aucun flux financier réel : le module trace une décision et un versement comptable, jamais un paiement effectif — le message d'avertissement s'affiche à chaque versement enregistré.
  • Le crédit respecte le choix d'identité : zata_sec (pseudonyme) apparaît dans l'advisory public, alors que le CSIRT voit en interne « Security Researcher BF », son nom d'affichage réel.
